# 教学与交互复核（2026-09-26）

此次迭代从八个同构节点面板改为五层课程地图、29 个拓扑实验与六种协议观察视图。以下区分自动验证和内容审阅，不把测试通过当作真实学习效果的证明。

## 第一轮：数据与因果检查

- 拓扑中的节点都是设备或明确标注的合并网络，协议栈在设备内部展示。
- 检查每个发送端、接收端和显式分支路径；所有路径只能经过已定义链路。
- ARP 广播分别到达 B、C 与网关，网关不转发二层广播；目标识别属于本地动作。
- VLAN 10 广播不出现在 VLAN 20 的端口，Trunk 保留 VLAN 分隔。
- 封装经过两台路由器，两次更换帧；TCP 端点不变。
- 路由器 TTL 耗尽时丢弃原包，回程 ICMP 是新报文。服务器不会收到原包。
- OSPF 故障后避开故障边；拓扑更新和后续业务转发分成两步。
- HTTP 新鲜缓存命中时没有请求箭头；条件验证区分 304 与 200。
- TCP 序号按字节解释，ACK 指下一期望字节；超时恢复与三重复 ACK 不混为同一路径。

新增测试覆盖了上述路径约束，并检查条件分支不会修改基础课程。修正了旧测试中固定八个课程的假设。

## 第二轮：真实浏览器交互检查

使用 Chromium 通过本地静态服务器验证：

- 29 个实验的 143 个步骤均能前进、回退、跳转，首尾按钮边界正确。
- 29 道自测能解锁、正确判分并记录；刷新后完成进度仍在。
- 三组条件对照能从起点重放并改变结果。
- SVG 设备可以键盘选中，操作后焦点保留；播放器和筛选控件可键盘操作。
- 自动播放、暂停、目录搜索、层级筛选、概念跳转与跨层导航正常。
- 320、390、768、1920 像素宽度检查无整页横向溢出；浏览器无页面错误及意外外部请求。
- localStorage 被禁用后播放器仍可使用。

第一轮截图暴露了设备命中区域挡住箭头，以及手机横向拓扑难以同时观察完整路径的问题。已修正透明命中区域，并为不同拓扑安排纵向手机坐标。

## 第三轮：图文一致性与可读性复核

- 时序图改用实际参与者的生命线，保证 ICMP 多跳、邮件多角色的箭头方向与文字一致。
- 给设备标签添加背景，避免斜向链路穿过文字。
- OSPF 单区域演示移除 BGP 的 AS 标签，防止混淆域内和域间路由。
- DHCP 明确客户端可在配置前接收链路单播，并约定 broadcast=0；应用租约后更新节点地址。
- IPv6 节点统一使用 IPv6 示例地址，并将本地图说明改为 NS 多播与 NA 应答。
- 状态摘要包含观察项名称，避免只显示无法解释的数值或序号范围。
- 手机阅读说明时保持播放控件可见，避免反复滚回顶部。
- 跳到最后一步不把所有前序步骤伪装成已访问；自测仍要求看过当前分支全部步骤。

## 对覆盖程度的判断

可演示部分覆盖五层主线、局域网、端到端传输、域内/域间路由、常用应用与安全。概念索引扩展到相邻主题，明确标记仅作概念解释的 STP、RIP、SLAAC、CDN 等；不把它们算作已实现独立演示。

后续适合继续深入的内容包括生成树收敛、距离向量的计数到无穷、完整 IPv6 地址配置、DNS 缓存分支、链路 CRC 错误注入及实际队列调度。这些未实现的过程不应通过当前实验名称暗示已经覆盖。
